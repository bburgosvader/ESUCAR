## Cómo mantener evidencia válida

1. Asignar las tarjetas a los miembros reales cuando se confirmen sus cuentas.
2. Añadir a cada tarjeta el commit o archivo revisado y el resultado de la comprobación.
3. Registrar incidencias reales y su solución; no crear errores ficticios para aumentar actividad.
4. Cada integrante debe efectuar y explicar sus propias contribuciones. No atribuirse trabajo de otra persona ni del asistente.
5. Adjuntar capturas o resultados de pruebas reales antes de mover las tarjetas de dispositivo a completadas.

El código preparado con asistencia no reemplaza la participación colaborativa exigida por IE 2.3.2.
