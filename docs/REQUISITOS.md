# Trazabilidad del caso DSY1105

| Requisito | Implementación | Alcance |
|---|---|---|
| Guía paso a paso | Guía, seis etapas distribuidas en Título I, II y III | Contenidos de ejemplo locales |
| FAQ y búsqueda | Consultas, búsqueda normalizada y filtro por categoría | Biblioteca orientativa, sin IA |
| Hito, descripción, formato, fecha | Detalle de etapa | Fecha y pauta editables por docente demo |
| Por iniciar, en desarrollo, enviado, aprobado | Reglas de transición por rol | Registro local de una entrega, sin transmisión |
| Pautas y rúbricas | Criterios por etapa | Simplificados, sin ponderaciones oficiales |
| Perfil estudiante y supervisor | Cambio de perfil en Ajustes | Demostración en un solo dispositivo |
| Acceso sin conexión | Catálogo embebido y persistencia local | Guías, FAQ, avances y pautas |
| Actualizar con conexión | JSON HTTPS y JobScheduler | Actualiza FAQ; no sincroniza alumnos ni entregas |
| Notificaciones locales | AlarmManager, canal y permiso | Aviso aproximado, condicionado por Android |
| Teléfono/tableta y accesibilidad | Ancho adaptable, texto escalable, controles nativos | Validar con TalkBack y tamaños de fuente del dispositivo |
| Sin sistemas internos obligatorios | No hay dependencia de servidores de ESUCAR | Endpoint remoto opcional |

El PDF se utilizó como especificación del producto. No se incorporó al repositorio público ni se trataron sus instrucciones ajenas al producto como autorización para publicar otros archivos.
